# Stock accounting and statement import release

PR #48 uses one stock calculation engine and shared same-day event ordering. The Group importer preserves statement trade order, stable IDs, precise app rewards, and fee overrides. Missing rounded rewards are excluded and flagged for exact entry. See [the import guide](the-group-import.md).

Interactive local browser verification was blocked by browser-to-server connectivity and is not claimed.

The historical development backlog in webapp/README.md is retained unchanged from main. This release note and the import guide carry the current feature status without deleting historical project documentation.

After successful merge and Pages deployment, select QSE, choose The Group, then use Cash ledger → Import The Group statement. Review the import summary before saving. Keep precise reward entries in the app; obtain exact values for any missing rewards.
